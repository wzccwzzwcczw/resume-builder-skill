# 简历体检清单（出稿后自查，逐条过）

## 内容
- [ ] 每段经历每条 bullet 都**动词开头**，没有"我/负责了"流水账
- [ ] 每条尽量带**量化结果**（数字/百分比/量级）
- [ ] 项目按 **背景难点→方案→角色→结果** 写清，不只罗列技术名词
- [ ] 技能只写**能扛住面试深挖原理**的，没写"精通"却讲不出底层
- [ ] 没有编造/夸大（每条都敢被追问"怎么做的/怎么测的"）

## 岗位对齐（ATS）
- [ ] 目标 JD 的关键词命中率 **≥ 80%**
- [ ] JD 原词照搬（同义词统一成 JD 用词），缩写+全称给一次
- [ ] 缺失关键词：真有的已嵌入；没有的标了 gap，没造假

## 排版 / 格式
- [ ] 投 ATS 渠道用 `--style ats`（单栏、标准标题、无图表、无 emoji）
- [ ] 段落顺序符合预期（默认：基本信息·教育·实习·项目·技能·荣誉）
- [ ] 校招 1 页 / 社招≤2 页
- [ ] 日期统一 `YYYY.MM`；联系方式齐全且正确
- [ ] 文件名 `姓名_岗位_简历`

## 细节
- [ ] 无错别字、中英标点统一、时态一致
- [ ] 没放无关个人信息（年龄/婚否/照片/身份证号）
- [ ] GitHub/作品集链接可访问（技术/设计/产品岗强烈建议放）
