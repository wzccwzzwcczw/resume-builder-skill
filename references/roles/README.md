# 岗位关键词库

## 用法（通用核心）
**不预置所有岗位**。通用能力靠两条：
1. **JD 现场抽取（万能兜底）**：不管什么岗位，从用户贴的 JD 里抽关键词去对齐——任意岗位/行业都能跑。
2. **预置库（加速 + 质量保险）**：下面是高频方向的关键词清单，命中目标方向时直接调用，写得更准更全。

预置文件：`backend.md` `frontend.md` `algorithm-ai.md` `product.md` `operations.md`（可继续加：client/test/data/design…）。
